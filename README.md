# 班級公告牆｜校內分享公版 v2

設計 by 楊依依老師｜Emily AI Studio

## 目前狀態

這是已完成本機操作驗收的靜態公版，可直接開啟 index.html，或使用下方 GitHub Pages 網址。

- 網站：https://liayangee-coder.github.io/classroom-announcement-wall/
- 原始碼：https://github.com/liayangee-coder/classroom-announcement-wall

**目前公告與設定儲存在使用者的瀏覽器，尚未接上雲端資料庫。** 老師各自開啟會有各自的資料；把網址傳給家長，不會自動同步老師在自己瀏覽器新增的公告。閱讀模式只是方便預覽，並非登入或存取權限。GitHub Pages 發布的是公版介面，沒有上傳老師瀏覽器內的公告、底圖或備份。

跨裝置共同讀取、管理員登入與正式發布屬於雲端階段，本壓縮檔不宣稱已完成這些功能。

## 開啟與更新

1. 將整個資料夾解壓縮，三個網頁檔案放在一起。
2. 用 Chrome 或 Edge 開啟 index.html。
3. 使用舊版者，先在原位置保留原檔；替換同一資料夾的 index.html、styles.css、app.js 後，重新整理。公告資料沿用原本的 emily-announcement-wall-v1 儲存鍵，不會因升級而清空。
4. 若改用另一個資料夾、瀏覽器或網址，資料可能無法自動沿用。請先從左上角看板選單「匯出備份」，再於新位置「匯入備份」。

## 老師可自行修改

- 上方「⚙」：網站名稱、副標題／老師署名、頁首與頁尾小標語、網站圖示。
- 看板標題旁「✎」：看板名稱與說明。
- 左上角網站名稱的「⌄」：切換看板或建立新看板。
- 「背景與色彩」：六組色調、任意底色與按鈕色、純色／漸層／點點／上傳底圖、底圖柔化。
- 「管理分類」：新增、改名、上移、下移與移除分類。
- 頁尾的「設計 by 楊依依老師｜Emily AI Studio」保留，沒有提供覆寫欄位。

公版初次開啟使用中性的「我的班級公告」及三個空白分類，不含依依老師班級的真實公告，也不含測試用公告。已使用舊版的使用者仍會讀取原有資料。

## 公告操作

- 按分類下方「＋」：新增公告時會預先選擇這個分類。
- 右下角「＋ 新增公告」：新增到目前篩選的分類；未篩選時可在表單選擇分類。
- 公告可選卡片色彩、上傳圖片、加文字或附件網址、置頂。
- 標題或「閱讀全文」可開啟完整公告；點圖片可放大。
- 公告上的「✎」可編輯與更換分類；「⌖」可切換置頂；「×」可移除並立即復原。
- 電腦可將卡片拖曳到其他欄位；手機請使用編輯視窗內的分類選單。
- 「篩選／版面」可開啟分類篩選及欄位／卡片切換。
- 欄位模式下，各欄各自往下捲動；所有欄位可橫向捲動，標題與分類列不會被長公告推走。
- 所有視窗的「×」「取消」都是獨立關閉操作，不會驗證必填欄位或誤存公告；支援 Esc 及點選視窗外關閉。

## 保留與備份

移除分類時，先指定公告移入的分類，或建立「未分類」。不會連同公告一起刪除。移除分類或公告後的提示提供「復原」。

上傳圖片支援 JPG、PNG、WebP（單張原檔最高 15 MB），會自動縮圖。瀏覽器儲存空間有限；空間不足時會提示，且這次修改不會誤顯示成功，原有資料保留。

匯出 JSON 備份包含看板、分類、公告、圖片、底圖與名稱設定。匯入時把看板新增為「名稱（匯入）」副本，保留現有看板與現有網站名稱設定。請保存備份，瀏覽器清除網站資料後無法憑本機檔案自動找回。

## GitHub Pages 檔案

儲存庫根目錄包含 index.html、styles.css、app.js、README.md 與 .nojekyll。GitHub Pages 從 main 分支的 /(root) 發布；修改 main 分支內的網頁檔案後，Pages 會重新建置。這會發布前端介面，不會將 localStorage 資料轉為雲端公告。

若從本機檔案移到這個網址，請先於原本網站匯出 JSON 備份，再於公開網站匯入；資料不會跨網址自動搬移。校內老師可共用這個網址，各自在自己的瀏覽器設定名稱及看板；使用另一台裝置時同樣需要匯入備份。
